GYM TRACKER — V1.6
1. Экспортируй JSON истории в настройках на iPhone. Не удаляй PWA, не меняй адрес сайта и не очищай данные Safari.
2. Распакуй архив и загрузи все файлы в корень существующего GYM-tracker (main). Commit changes. После успешной публикации закрой и открой приложение онлайн; в настройках должна быть V1.6.
3. При переходе с V1.5 на V1.6 ничего удалять из репозитория не нужно. Если старые файлы opengym3d.js и папка visuals остались от V1.4, они не используются. Не удаляй visuals.js и не очищай данные сайта.
4. Изображения из Open Exercise Illustrations (CC0) загружаются при открытии карточки. Динамические движения показывают 2–3 кадра с плавной сменой; кнопки 1/2/3 позволяют остановиться на кадре. Удержания — статические. Встроенные соответствия: 38 из 49 по каталогу, 6 похожих вариантов явно помечены, 5 без подходящего изображения. Для некоторых силовых движений указан пример оборудования. Иллюстрации созданы ИИ, техника не проверена тренером; текстовые инструкции прежние.
5. Библиотека → Загрузить каталог иллюстраций: добавляет каталог CC0 в локальную базу, не скачивает 796 картинок. Прежний импорт текстового каталога и пользовательских файлов сохранён.
6. Библиотека → Скачать изображения моей программы для офлайн: вручную сохраняет только изображения активных упражнений и мобильности/заминки, до 5 МБ. После замены упражнений повтори загрузку. При ошибке показывает число несохранённых кадров. Очистка офлайн-изображений не удаляет историю, каталог или личные файлы. Safari может вытеснить кэш.
7. Проверь офлайн: открой заранее скачанное упражнение в авиарежиме. Без скачанного пакета картинки требуют сети; дневник работает офлайн отдельно.
8. История, черновики, настройки и замены остаются под gymtracker.v1; IndexedDB gymtracker-library сохраняется. Экспорт JSON не включает бинарные файлы и внешние каталоги. Импортированные вручную изображения имеют приоритет как пользовательские данные.
9. Ограничения: файлы WebP не удалось скачать в среде разработки, поэтому архив не содержит изображения; HTTP/CORS и внешний каталог в реальном iPhone не проверены. Сопоставление по метаданным не является визуальной проверкой каждого кадра. Системный кэш Safari не полностью управляем приложением.


ИЗМЕНЕНИЯ V1.6
• Активная тренировка: тёмный фон и лаймовый акцент, компактная иллюстрация, круговой индикатор выполненных подходов текущего упражнения, прогресс всей тренировки, четыре быстрые кнопки: Техника, История, Заменить, Заметки. Никаких служебных плашек типа упражнения/оборудования. Поля веса и повторений, дополнительные подходы, предыдущие результаты и план сохранены.
• Кнопка «Завершить» доступна на любом упражнении и заминке. Меню: «Продолжить тренировку», «Завершить тренировку и сохранить данные», «Отменить тренировку». Отмена требует подтверждения и сбрасывает только текущий черновик. Завершение сохраняет тренировку в истории; для неполной сессии требуется подтверждение, для пустой — сначала отметь хотя бы один подход. На общем списке доступно «Управление тренировкой».
• Библиотека → Управление иллюстрациями: личный файл, привязка к каталогу, удаление привязки/файла, массовый импорт. Поиск и выбор упражнения (включая мобильность и заминку). В обычных карточках — только изображения и техника.
• Таймер по умолчанию остаётся ручным: запуск нажатием на плитку «Отдых»; существующая настройка автоматического таймера сохранена.
• Схема локальных данных, IndexedDB, библиотеки, ссылки, офлайн-пакет и источник изображений не изменены.
• Проверено на тестовых данных V1.5: перенос истории, черновика, программ, заметок, мобильности, настроек, привязок; отмена с подтверждением, продолжение, сохранение неполной тренировки, вес с запятой, дополнительные подходы, ручной таймер. Проверено обновление service worker без удаления офлайн-пакета. Внешний вид и поведение на реальном iPhone предстоит проверить.
