GYM TRACKER — V1.8
1. Экспортируй JSON истории в настройках на iPhone. Не удаляй PWA, не меняй адрес сайта и не очищай данные Safari.
2. Распакуй архив и загрузи все файлы в корень существующего GYM-tracker (main). Commit changes. После успешной публикации закрой и открой приложение онлайн; в настройках должна быть V1.8.
3. При переходе с V1.7 на V1.8 ничего удалять из репозитория не нужно. Если старые файлы opengym3d.js и папка visuals остались от V1.4, они не используются. Не удаляй visuals.js и не очищай данные сайта.
4. Изображения из Open Exercise Illustrations (CC0) загружаются при открытии карточки. Динамические движения показывают 2–3 кадра с плавной сменой; кнопки 1/2/3 позволяют остановиться на кадре. Удержания — статические. Встроенные соответствия: 38 из 49 по каталогу, 6 похожих вариантов явно помечены, 5 без подходящего изображения. Для некоторых силовых движений указан пример оборудования. Иллюстрации созданы ИИ, техника не проверена тренером; текстовые инструкции прежние.
5. Библиотека → Загрузить каталог иллюстраций: добавляет каталог CC0 в локальную базу, не скачивает 796 картинок. Прежний импорт текстового каталога и пользовательских файлов сохранён.
6. Библиотека → Скачать изображения моих программ для офлайн: вручную сохраняет изображения упражнений всех созданных групп и мобильности/заминки, до 5 МБ. После замены упражнений повтори загрузку. При ошибке показывает число несохранённых кадров. Очистка офлайн-изображений не удаляет историю, каталог или личные файлы. Safari может вытеснить кэш.
7. Проверь офлайн: открой заранее скачанное упражнение в авиарежиме. Без скачанного пакета картинки требуют сети; дневник работает офлайн отдельно.
8. История, черновики, настройки и замены остаются под gymtracker.v1; IndexedDB gymtracker-library сохраняется. Экспорт JSON не включает бинарные файлы и внешние каталоги. Импортированные вручную изображения имеют приоритет как пользовательские данные.
9. Ограничения: файлы WebP не удалось скачать в среде разработки, поэтому архив не содержит изображения; HTTP/CORS и внешний каталог в реальном iPhone не проверены. Сопоставление по метаданным не является визуальной проверкой каждого кадра. Системный кэш Safari не полностью управляем приложением.


ФУНКЦИИ, СОХРАНЁННЫЕ В V1.8
• Активная тренировка: тёмный фон и лаймовый акцент, иллюстрация на всю доступную ширину без наложения и без кругового индикатора, счётчик выполненных подходов рядом с таблицей и прогресс всей тренировки, четыре быстрые кнопки: Техника, История, Заменить, Заметки. Никаких служебных плашек типа упражнения/оборудования. Поля веса и повторений, дополнительные подходы, предыдущие результаты и план сохранены.
• Кнопка «Завершить» доступна на любом упражнении и заминке. Меню: «Продолжить тренировку», «Завершить тренировку и сохранить данные», «Отменить тренировку». Отмена требует подтверждения и сбрасывает только текущий черновик. Завершение сохраняет тренировку в истории; для неполной сессии требуется подтверждение, для пустой — сначала отметь хотя бы один подход. На общем списке доступно «Управление тренировкой».
• Библиотека → Управление иллюстрациями: личный файл, привязка к каталогу, удаление привязки/файла, массовый импорт. Поиск и выбор упражнения (включая мобильность и заминку). В обычных карточках — только изображения и техника.
• Таймер по умолчанию остаётся ручным: запуск нажатием на плитку «Отдых»; существующая настройка автоматического таймера сохранена.
• Ключ локального хранения gymtracker.v1, IndexedDB, библиотеки, ссылки, лимит офлайн-пакета и источник изображений сохранены. Черновики теперь привязаны к группе, дате и комплексу; старые записи автоматически переносит миграция.
• Проверено на тестовых данных V1.5: перенос истории, черновика, программ, заметок, мобильности, настроек, привязок; отмена с подтверждением, продолжение, сохранение неполной тренировки, вес с запятой, дополнительные подходы, ручной таймер. Проверено обновление service worker без удаления офлайн-пакета. Внешний вид и поведение на реальном iPhone предстоит проверить.


ГРУППЫ И КАЛЕНДАРЬ
• Вкладка «Тренировка» открывает список групп. Существующая программа A/B/C и все предыдущие записи относятся к группе «Для мобильности».
• Нажми «Создать группу»: введи имя и выбери пустую программу или копирование уже существующей. У копии свои идентификаторы упражнений, черновики, целевые веса и история; старая группа не меняется.
• Внутри группы — горизонтальная полоса дат. Прокручивай её пальцем в обе стороны и нажимай нужную дату. Салатовая точка и A/B/C означают только сохранённые завершённые тренировки этой группы; выбор комплекса, начатая или отменённая тренировка не ставят отметку.
• В настройках группы (⚙) можно переименовать группу и редактировать комплексы: добавить упражнения из библиотеки или убрать из списка с подтверждением. При наличии начатого черновика для комплекса изменение его состава блокируется до завершения/отмены, чтобы не потерять введённые данные. Заменить отдельное упражнение по прежним правилам можно во время тренировки. Пустая группа не имеет готовой заминки; при копировании она переносится.
• Черновики сохраняются отдельно для каждой даты, комплекса и группы. Другие незавершённые тренировки доступны в раскрывающемся списке внутри группы. История отображает название группы; в разделе «Прогресс» можно выбрать группу.
• Программные тесты: перенос с V1.5/V1.6, импорт резервных копий V1.6/V1.7, календарь, создание и переименование, копирование и пустая группа, независимость данных, замена и удаление упражнения, сохранение и отмена, счётчик подходов, ручной таймер и сохранение офлайн-кэша. Внешний вид и реальные действия в Safari на iPhone ещё необходимо проверить.


НОВОЕ В V1.8
• Минималистичный календарь: один ряд дат, примерно семь дней в видимой области; без заголовков недели/месяца, выбранного диапазона, стрелок и подписи даты. При открытии группы выбрана сегодняшняя дата. Свайп прокручивает даты непрерывно в обе стороны; выбор даты и комплекса не меняет историю.
• Отметки вычисляются только из сохранённой истории своей группы. Если за день сохранены несколько комплексов, отображаются их буквы. Старые отметки планов из V1.7 игнорируются; данные черновиков, групп, программ, заметок, весов и истории не удаляются.
• Нажми на ячейку фактического веса или повторений в существующей таблице. Откроется цифровая клавиатура GYM снизу, активная ячейка и номер текущего подхода подсветятся. Вводятся цифры, для веса разрешена запятая, удаление символа — отдельной клавишей. Первое нажатие цифры заменяет предзаполненное значение; «Далее» позволяет оставить его без изменений. Для упражнений без веса переход выполняется сразу между повторениями или секундами.
• Кнопка «ДАЛЕЕ →» последовательно переводит фокус: вес → повторения → вес следующего подхода. После последнего поля — «ГОТОВО ✓». Стрелка вниз скрывает клавиатуру. Физическая клавиатура: цифры, запятая/точка, Backspace, Enter, Escape. Подходы отмечаются только вручную, как раньше.
• Ввод, отметка, добавление и удаление подходов обновляют локальную таблицу, а не всю страницу. Если очередное поле закрыто клавиатурой, прокрутка выполняется только до его видимой зоны. Иллюстрация не перезагружается при вводе.
• Единая тёмная палитра и салатовый акцент во всех разделах, единый стиль иконок и элементов управления. Программы упражнений, таймер, библиотека, история, заминка, мобильность, замена упражнений и офлайн-источник сохранены.
• Проверены 26 программных сценариев на тестовых данных, включая совместимость V1.5–V1.7, календарные отметки, независимость групп, последовательность полей, дробные веса, сохранение черновиков, восстановление JSON и обновление service worker без удаления офлайн-пакета. Жесты прокрутки и визуальное поведение на реальном iPhone следует проверить после установки.
