GYM TRACKER — V1

Установка на iPhone
1. Распакуй архив. Все файлы должны находиться в одной папке.
2. Размести содержимое папки на статическом HTTPS-хостинге (например, GitHub Pages). Открывать нужно опубликованный URL, а не архив. На хостинге не требуется серверная логика.
3. Открой URL в Safari → Поделиться → На экран «Домой» → Добавить.
4. Открой приложение с экрана «Домой», пока есть интернет. В настройках проверь статус офлайн-кэша. Затем проверь работу в авиарежиме.

Локальный запуск на компьютере: в папке проекта выполни python -m http.server 8000 и открой http://localhost:8000. Для установки на телефон нужен HTTPS.

Данные сохраняются локально в браузере. Облака, регистрации и синхронизации нет. Экспортируй JSON в настройках, чтобы сохранять резервные копии. При смене устройства или адреса хостинга импортируй копию.

Вес гантелей — одной гантели. В подтягиваниях и брусьях 0 кг означает отсутствие дополнительного веса. Повторения односторонних упражнений записываются на сторону. Для резинки — сопротивление в заметках, для планки — секунды.

Таймер основан на времени окончания; уведомления при заблокированном экране не предусмотрены. План фиксирован по последней версии PDF, без ходьбы в заминках. Редактирование программы и видео упражнений пока не реализованы. Прогресс показывает максимальный вес (или повторы/секунды для упражнений без веса), а не оценку силы.

V1.2: ввод веса с запятой, таймер мобильности, раскрытие техники заминки и мобильности, замена упражнения из каталога (без изменения старой истории). GIF V1.1 сохранены; новые анатомические материалы не включены.

V1.3 — Библиотека
1. Сделайте экспорт JSON истории из текущего приложения. Обновите файлы на том же GitHub Pages.
2. В приложении откройте вкладку «Библиотека» → «Загрузить каталог (интернет)». Каталог сохраняется в IndexedDB. Если загрузка не проходит, скачайте data/exercises.json из https://github.com/therustyblade/exercises-dataset и импортируйте через кнопку «Импорт exercises.json».
3. Поиск, фильтры и техника работают офлайн после импорта. Названия из источника на английском, инструкции на русском при наличии.
4. Для правомерно полученных локальных изображений: «Импорт GIF / фото по именам файлов» сопоставляет исходные имена из каталога. Можно выбирать несколько файлов. Для оригинального упражнения откройте «Техника» → «Связать с упражнением из библиотеки» либо выберите локальный файл. Для мобильности и заминки нажмите на название упражнения и используйте те же инструменты. Медиа не загружаются на GitHub. Не импортируйте материалы без необходимых прав.
5. Замена силового упражнения: «Заменить» → поиск → выбор упражнения → настройка подходов/повторов. Старые записи сохраняются.
6. Экспорт JSON сохраняет историю и настройки, но не бинарные GIF и не весь каталог. Храните исходные файлы отдельно. Safari может очистить локальное хранилище. Проверьте офлайн на iPhone после импорта.

V1.4 TEST — OpenGym3D (дополнение к V1.3)
1. Перед обновлением экспортируйте JSON истории. Загрузите все файлы архива в существующий репозиторий (не меняйте адрес приложения). Не удаляйте приложение с iPhone и не очищайте данные сайта.
2. Библиотека → OpenGym3D — каталог и проверка соответствий. Запрашивает опубликованный exercises.json напрямую из https://assiamahs.github.io/opengym3d/ и показывает все записи, лицензии, QA и совпадения для 24 силовых, 5 запасных и 20 уникальных названий мобильности/заминки, а также загруженного внешнего каталога. Экспорт отчёта JSON — по кнопке. Точные названия и явные синонимы — только кандидаты, не подтверждение техники.
3. Откройте упражнение → Смотреть 3D (тест) → выберите подходящий вариант по названию и оборудованию. Вращение, масштабирование, воспроизведение/пауза, скорость. Только при наличии сети. Прежняя иллюстрация и техника остаются.
4. Модели загружаются по запросу с cache:no-store, временный Blob URL отзывается при закрытии; GLB не входит в Cache Storage, IndexedDB или localStorage. Каталог OpenGym3D существует только в памяти текущей сессии. Браузер может отдельно кэшировать код просмотрщика, а системное хранение Safari не контролируется целиком. Встроенные GIF и ранее импортированные вручную файлы V1.3 не удалены.
5. Консервативный фильтр: только опубликованные записи с qa.pass=true, license.pack=true и MIT/CC0/CC0-1.0. Mixamo и неизвестные лицензии исключены. Условия исходного проекта: https://github.com/AssiamahS/opengym3d/blob/main/docs/ASSET_PIPELINE.md ; авторские права на исходные модели не передаются этим архивом. Модели не включены в архив. Viewer: @google/model-viewer 4.0.0 через jsDelivr, Apache-2.0.
6. Ограничение теста: актуальный публичный manifest и GLB не удалось получить из среды разработки. CORS и реальное воспроизведение на iPhone не проверены. Проверена программная логика на искусственных данных. Если каталог недоступен, приложение явно сообщает об ошибке и не показывает ложный результат. Основной дневник работает независимо от 3D.
