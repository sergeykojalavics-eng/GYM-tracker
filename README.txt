GYM TRACKER — V1.5
1. Экспортируй JSON истории в настройках на iPhone. Не удаляй PWA, не меняй адрес сайта и не очищай данные Safari.
2. Распакуй архив и загрузи все файлы в корень существующего GYM-tracker (main). Commit changes. После успешной публикации закрой и открой приложение онлайн; в настройках должна быть V1.5.
3. Старый файл просмотрщика opengym3d.js можно удалить из GitHub отдельно (веб-загрузка не удаляет отсутствующие файлы). Старую папку visuals со схемами GIF также можно удалить: V1.5 не использует её. Не удаляй другие файлы и не очищай данные сайта.
4. Изображения из Open Exercise Illustrations (CC0) загружаются при открытии карточки. Динамические движения показывают 2–3 кадра с плавной сменой; кнопки 1/2/3 позволяют остановиться на кадре. Удержания — статические. Встроенные соответствия: 38 из 49 по каталогу, 6 похожих вариантов явно помечены, 5 без подходящего изображения. Для некоторых силовых движений указан пример оборудования. Иллюстрации созданы ИИ, техника не проверена тренером; текстовые инструкции прежние.
5. Библиотека → Загрузить каталог иллюстраций: добавляет каталог CC0 в локальную базу, не скачивает 796 картинок. Прежний импорт текстового каталога и пользовательских файлов сохранён.
6. Библиотека → Скачать изображения моей программы для офлайн: вручную сохраняет только изображения активных упражнений и мобильности/заминки, до 5 МБ. После замены упражнений повтори загрузку. При ошибке показывает число несохранённых кадров. Очистка офлайн-изображений не удаляет историю, каталог или личные файлы. Safari может вытеснить кэш.
7. Проверь офлайн: открой заранее скачанное упражнение в авиарежиме. Без скачанного пакета картинки требуют сети; дневник работает офлайн отдельно.
8. История, черновики, настройки и замены остаются под gymtracker.v1; IndexedDB gymtracker-library сохраняется. Экспорт JSON не включает бинарные файлы и внешние каталоги. Импортированные вручную изображения имеют приоритет как пользовательские данные.
9. Ограничения: файлы WebP не удалось скачать в среде разработки, поэтому архив не содержит изображения; HTTP/CORS и внешний каталог в реальном iPhone не проверены. Сопоставление по метаданным не является визуальной проверкой каждого кадра. Системный кэш Safari не полностью управляем приложением.
